probe-rs enumerates every USB probe before it opens the one `--probe` names, a CMSIS-DAP TCP probe included, so a USB device the host cannot enumerate delays every command, `read` of one word, by 85 s, with no message at the default log level; it showed only as a gap before `list_wlink_devices` at `RUST_LOG=probe_rs=debug`. Met in R12.40's Hazard3 board run, with a halted BOOTSEL Pico 2 on the bus (SR-680).

Completion: A probe selector naming a network transport opening it without listing USB probes.
