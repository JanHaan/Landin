RP2040's description boots through a port of pico-sdk's generic second stage, which reads the flash with the serial 03h command at a quarter of the system clock, so every cache miss in flash costs one serial read; pico-sdk's default for the Pico, `boot2_w25q080.S`, reads four bits a clock, and it also writes the flash's non-volatile QE bit when that is clear, a path the Pico H's W25Q16JV, shipped with QE set, would never run. Chosen for the first board because every instruction of the generic stage runs on it and it fits any RP2040 board's flash.

Completion: A quad-read second stage for that flash in its description, every path of it executed on the board.
