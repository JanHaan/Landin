Nothing reports what a routine costs on an emulator lane. Choosing R13.80's hash took a script that counts QEMU's `-d exec` lines at one instruction per block up to a completion label's address; RV32's lines carry no symbol for the start file, the Xtensa label is the link symbol `_landin_xtensa_fixture_stopped`, and the ESP32-S3's counts move between runs, so a difference of two iteration counts was the only per-call figure.

Completion: `--program` reporting the instructions a run executed, per lane.
