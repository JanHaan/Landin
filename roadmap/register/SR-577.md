On a Cortex-M profile with a float unit, a framed routine that holds any assembly block saves and restores all of d8 to d15, 64 bytes of stack and sixteen transfers, although a block must now declare each callee-saved float register it names (D630), so the declared set is known. Kept conservative when float operands came after the frame's save in R12.30.

Completion: The routine saving only the d registers its blocks declare and its own code uses.
