A function value given a routine whose signature differs is L0301 "this function has a different signature", naming neither signature nor the part that differs, so a `from held` against a plain `from`, or one `escaping into` against `escaping`, reads as identical text on the page. Met in R13.92 writing `negative/held-result-refusals`.

Completion: The note spelling both signatures, or the first part where they differ.
