Two `refine compile` runs that write into one output directory at once, as `make -j` starts them, can refuse each other with L0005, "another process holds its lock; retry when that process has finished": each inspects the other's `.refine-publication-` workspace and waits two seconds for its lock (D1049). Nothing says that outputs sharing a directory cannot be built in parallel, and the refusal reads as a stale lock. Met in R18.10, where `scripts/measure.py`'s concurrent builds failed until each took a directory of its own.

Completion: Concurrent compiles into one directory succeed, or the refusal names the concurrent build and the documentation says to build into separate directories.
