The STM32H753's SVD describes none of the Cortex-M7's System Control Space, so the board application reaches VTOR, CPACR, CCR, the NVIC's enables and SysTick through a module of its own, `scs`, of volatile accesses at addresses read out of the Armv7-M Architecture Reference Manual; the RP2040's SVD gave its `ppb` module, and `platform/cortex_m` offers barriers and the interrupt mask but no System Control Space register, though every M-profile board has them at the same addresses. Met writing the STM32H753 board application in R12.30.

Completion: The architecture's System Control Space as a library module or a generated one of its own, which the STM32H753 board imports instead.
