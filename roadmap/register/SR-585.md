D255 has no Armv8-M level with the optional DSP extension, so a Cortex-M33 that has it, as RP2350's do, builds at `armv8-m.main` and `compiler.feature.dsp` is false there, and a `cortex-m33` description admits no `armv7e-m` build either, since its DSP instructions are optional. Left out of R12.30.

Completion: A level in D255's table, `armv8-m.main+dsp` in GCC's spelling, holding `dsp`, admitted for a core whose description says it has the extension, with its tool arguments and an executed fixture on the AN505.
