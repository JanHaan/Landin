A static Linux program cannot install a signal handler: x86-64's `rt_sigaction` needs a restorer the library cannot write, so `libc.sigaction` with a handler, `libc.handling`, works only with `--link=libc`. Met in R13.79 typing the handler. Merged: SR-1110, an event loop on a worker thread cannot watch signals on Linux: since D1126, which the maintainer confirmed, only the process's first thread may `signal.watch`, a refusal on one system only, whose alternatives the decision's entry records.

Completion: A handler installed without the C library, with the restorer the static start supplies, and signals watched from any one thread of a process.

Kept: No item on Linux signals has been taken up since R13.79, so a static program still cannot install a handler.
