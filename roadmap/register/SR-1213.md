A static Linux program cannot install a signal handler: x86-64's `rt_sigaction` needs a restorer the library cannot write, so `libc.sigaction` with a handler, `libc.handling`, works only with `--link=libc`. Met in R13.79 typing the handler.

Completion: A handler installed without the C library, with the restorer the static start supplies.
