An import path with a hyphen or a dot, `import janhaan/refine-build/lines` or `import github.com/janhaan/refine-build/lines`, is L0110 "this begins no declaration", pointing at the path's rest with [1740]'s note: nothing says that each segment of an import path is an identifier, or which character broke it. Met naming refine-build's package (friction entry 11), found by trying three spellings.

Completion: the refusal saying that a segment is an identifier and naming the character.
