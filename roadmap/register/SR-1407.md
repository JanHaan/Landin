No function can be declared as one that leaves only by failing, so a helper that reports a problem and always fails cannot end an `else` block that owes a value: `x: T = f() else (problem) try gave_up(host, what, problem) end` is L0332 "this control block can fall through without producing a value", and `-> noreturn ! refused` is L0343, since `noreturn` takes no errors. Met writing refine-build (friction entry 5), whose thirty call sites each carry their own `fail`.

Completion: a signature that says a function leaves only by failing, accepted as an `else` block's end, or the reason recorded.
