`scripts/test.sh` cannot run the test program of a build made with extra link switches. R23.40 built `refine` and the test program with `./scripts/build.sh -q -R -largs -static ...` in a variant tree, then had to run the test program by a wrapper of its own copying `test.sh`'s last lines, because `test.sh` calls `build.sh -q` with no switches, which would rebuild the tree without them, and takes no switch of its own to pass on; nothing in the documents says so, and neither tool refuses.

Completion: a static build is a build mode or variant `env.sh` and `build.sh` know, so `scripts/test.sh` and `dev-test.sh` build and run it as they do the others, or `test.sh` passes build switches to `build.sh`; `docs/process.md`'s command reference shows the static build and its test run.
