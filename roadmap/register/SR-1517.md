`scripts/package.sh` given another architecture's `refine` fails inside with `objcopy: Unable to recognise the architecture of the input file`, naming a temporary staging path and making no archive. R23.40 met it packaging the arm64 static build on its x86-64 host and repackaged inside the flake's `aarch64-linux` shell under emulation. The script runs the host's `objcopy` to split the debug information and does not say it packages only the host's own binaries.

Completion: `package.sh` refuses another architecture's executable at the start, saying it packages for the host it runs on and naming the way to package for another (that architecture's shell or binutils), or it takes the matching `objcopy` itself.
