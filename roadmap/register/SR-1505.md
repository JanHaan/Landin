No command builds one Cortex-M fixture at a chosen level, objective and description and counts what it executes: `measure.py instructions` builds and counts the whole firmware set at armv6-m, armv7-m and armv8-m.main only, never armv7e-m or a description with a float unit, and `measure.py count` counts an image someone else built. R16.26's subagent wrapped `measure.py`'s internal `build()` for it; R16.27 measured the firmware mandelbrot on the AN500 description (the float unit's measure, SR-596's) with a hand-written `refine compile ... --root=environments/cortex-m/lanes ... lane-mps2-an500.ldn` before `measure.py count`, and its packed-field program the same way.

Completion: One command, a `measure.py count` that takes a fixture or a source list with `--level`, `--optimize` and a description, building and counting it, documented in `docs/measurement.md`.
