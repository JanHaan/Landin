`python3 scripts/item.py gate ITEM --main --watch` keys its watch directory by commit alone, so after a failed gate is rerun on the same commit it prints "already watched" with the old run's directory, whose `result.json` holds the stale verdict, and starts no watch of the rerun. Met in R16.10 following main's gate.

Completion: A rerun or a newer attempt of the same commit watched afresh, or the message naming the stale run and how to watch the new one.
