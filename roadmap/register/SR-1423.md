A routine holding an assembly block gets no caller-saved register, no in-place read and whole-routine slot spans on x86-64, and no register at all on arm64 (`Has_Assembly`), where D248 asks only that nothing the block overwrites, the call-clobbered set and the callee-saved registers it names, holds a value across it. R16.10 measured a 4,096-element sum loop with an empty block at 2.29 times the instructions of the same loop without it on x86-64 (6.55 G against 2.87 G) and 45 instructions against 29 on arm64. No workload pays it: only `platform/linux`'s `system_call` and the thread start carry a block, and neither loops.

Completion: Each allocator treats a block as D248 describes it, a call that also overwrites the registers it names, measured on that loop.
