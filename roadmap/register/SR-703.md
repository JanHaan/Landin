A `--debug=full` Darwin image is likely not reproducible: ld64's debug map records the object's path and modification time. Native R13.76 probes measured an additional residue of private publication staging: after publication, `dsymutil --dump-debug-map` warns about the retired private object path even though the retained object exists beside the executable. The published UUID-bound dSYM remains the debugger artifact; a later bundle rebuild needs its object paths resolved. Two-build identity was not measured; Linux debug images are identical in one directory.

Completion: Two `--debug=full` Darwin links in one directory measured, their path/time residue resolved or declared in `docs/targets.md`, and retained-object lookup supplied when bundle regeneration is offered.
