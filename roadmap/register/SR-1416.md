A program cannot learn the name it was run by: `io.argument_at` starts at the first argument after the program's name, C's `argv[1]`, and nothing in `core/io` gives `argv[0]`. A contributed command answering `--describe`, which the dispatcher holds to its file's name `refine-NAME`, has to write its name in, so a copy under another name describes itself wrongly and is refused; nor can a usage line say the name the program was called by. Met writing refine-build (friction entry 17).

Completion: the program's name, as the host passed it, readable through `core/io`'s process concept, with its fakes giving one.
