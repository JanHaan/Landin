# Q-66 — From which address is the one-line install script served?

Asked by R23.30 on 2026-11-20, when the item was planned.

R23.30's script is fetched with `curl ... | sh`, and the address in that
command is printed in the documentation and copied into other people's
scripts and READMEs, so it has to stay valid for as long as the project
does. Which domain and host the project commits to is the maintainer's.

**Options:**

1. `https://www.701.dev/install.sh`, published with the site by the Pages
   workflow from the repository's copy.
2. A release asset, through GitHub's
   `https://github.com/701-dev/Landin/releases/latest/download/install.sh`.
3. The file on main, through `raw.githubusercontent.com`.

**Recommendation:** option 1. The project's own domain survives a move of
host, as the move from `JanHaan` to `701-dev` showed for the others; the
site is already published from the repository; and the script is the same
for every release, since it asks which archive to fetch.

**Default until answered:** the script is served from the project's site,
`https://www.701.dev/install.sh`, published with it from the repository.

**What waits on the answer:** only the address R23.30 documents; the script
and its controls do not depend on it.

**Answer (2026-11-21, the maintainer):** option 1. The script is served
from `https://www.701.dev/install.sh`, published with the site by the
Pages workflow from the repository's copy, and that address is the one the
documentation prints. Closed.
