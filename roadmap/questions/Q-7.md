# Q-7 — Emit the Darwin determinism manifests with the release compiler?

Asked by R17.50 on 2026-11-17, and filed by R17.20.

Each host of the `determinism` workflow emits a manifest of assembly
digests for every positive fixture, on every target, in every
optimization and specialization profile, and the manifests must agree.
Every host emits with its debug compiler, the Ada build that runs its
own assertions as it compiles. `build-modes` separately holds the
release compiler to the debug one's bytes, on Linux x86-64 only.

The two Darwin manifest shards take about 32 of the gate's roughly 115
macOS job-minutes, and the account's five macOS runners set when the gate
ends (Q-6). Most of a shard's time is the debug compiler's speed. Emitting
with the release compiler would shorten them, but it changes what the
evidence is, which is yours to decide.

**Options:**

1. Keep the debug compiler on every host. The Darwin manifests keep their
   cost, and the debug compiler's assertions keep running over the whole
   corpus in every profile on Darwin.
2. Emit Darwin's manifests with its release compiler and keep the debug
   compiler on Linux. The agreement then also holds Darwin's release
   build to Linux's debug one, a cross-host `build-modes`, while the
   debug compiler's assertions over the non-default profiles run on
   Linux alone. What it saves would be measured on one gate run first.
3. Emit every host's manifests with its release compiler. That is the
   same change everywhere, and the profiles' assertions then run only
   where `build-modes` and the suites run them.

**Recommendation:** option 2, taken only if one measured gate run shows it
moving the gate's end. The release compiler is the one people run, Linux
keeps the debug compiler's assertions over every profile, and the
`darwin-host` suites keep running the debug compiler on Darwin.

**Default until answered:** option 1, the debug compiler on every host;
nothing changes.

**What waits on the answer:** nothing; the gate keeps its present length
meanwhile, and this answer and Q-6's together decide how far the macOS
floor can fall.

**Answer (2026-11-19, the maintainer):** option 1: every host keeps
emitting its manifests with the debug compiler. Closed.
